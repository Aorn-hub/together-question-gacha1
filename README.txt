# Aid Together 質問ガチャ

サークル内向けの質問ガチャサイトです。

## ファイル
- `index.html` — 画面
- `style.css` — デザイン・アニメーション
- `script.js` — 81問、ガチャ処理、重複防止、リセット、質問一覧
- `assets/` — 使用画像

## 仕様
- 白背景
- 「質問ガチャ」タイトル
- Aid Togetherのガチャマシン
- ガチャ本体の揺れ → カプセル落下 → 排出口から出る → バウンド → 中央へ → 開封 → 質問表示
- 同じサイクルでは質問が重複しない
- 進行状況はブラウザのlocalStorageに保存され、リロードしても続きから再開
- 全問終了後はリセット可能
- 質問一覧をモーダル表示
- `noindex, nofollow` を設定

## 注意
`noindex` は検索エンジンへの掲載を抑止する設定で、URLを知っている人へのアクセス制限ではありません。
